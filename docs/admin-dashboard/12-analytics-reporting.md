# 12 — Analytics & Reporting

## Dashboard Metrics

### Revenue Metrics
- **GGR (Gross Gaming Revenue)**: Total bets - total wins
- **NGR (Net Gaming Revenue)**: GGR - bonuses - affiliate commissions
- **Hold %**: GGR / Total Wagered (should be ~4% matching house edge)

### Player Metrics
- DAU (Daily Active Users)
- WAU (Weekly Active Users)
- MAU (Monthly Active Users)
- New registrations per day
- Conversion: Registration → First Deposit
- Retention: D1, D7, D30

### Financial Metrics
- Average deposit amount
- Average withdrawal amount
- Deposit/Withdrawal ratio
- Average player lifetime value (LTV)
- Revenue per user (ARPU)

### Game Metrics
- Rounds per hour
- Average bets per round
- Average bet amount
- Cash-out distribution chart
- Most common cash-out multiplier

## Charts

1. **Revenue trend** (line chart, 7/30/90d)
2. **Player growth** (area chart, cumulative)
3. **Bet volume heatmap** (by hour of day / day of week)
4. **Crash distribution** (histogram of crash points)
5. **Retention curve** (cohort-based)
6. **Top players** (bar chart, by wagered/won)
7. **Affiliate performance** (bar chart, by revenue)
8. **Deposit sources** (pie chart)

## Reports (Exportable)

| Report | Frequency | Contents |
|--------|-----------|----------|
| Daily P&L | Daily | Revenue, costs, net profit |
| Weekly Summary | Weekly | All KPIs, top events |
| Monthly Financial | Monthly | Full financial statement |
| Player Cohort | On-demand | Retention by signup week |
| Affiliate Report | Weekly | Commission calculations |
| Risk Report | Daily | Alerts, actions taken |

## Export Formats
- CSV (all tabular data)
- PDF (formatted reports with charts)
- JSON (for programmatic access)
