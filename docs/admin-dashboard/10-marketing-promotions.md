# 10 — Marketing & Promotions

## Promotion Types

### 1. Welcome Bonus
- Triggered on first deposit
- e.g., 100% match up to KSh 1,000
- Wagering requirement: 3x bonus amount

### 2. Deposit Match
- Promo code-based
- e.g., Code "WEEKEND50" = 50% match up to KSh 500
- Limited uses, expiry date

### 3. Free Bets
- Admin awards free bet credits to specific users
- Credits used before real balance
- Winnings from free bets are withdrawable (minus the free bet amount)

### 4. Cashback
- Automatic % return on net losses
- e.g., 10% cashback on weekly losses
- Credited every Monday

### 5. Referral Bonus
- Both referrer and referee get bonus
- e.g., Referrer gets KSh 100, new player gets KSh 50
- Only after referee's first deposit

### 6. Chat Rain
- Admin drops random amounts in chat
- First N users to claim get the bonus
- Engagement driver during slow hours

## Notifications/Broadcasts

### Channels:
- In-app banner (top of game screen)
- Push notification (if PWA)
- SMS (via Africa's Talking)

### Targeting:
- All users
- Inactive 3+ days
- High balance (> KSh 5K)
- Low balance (< KSh 100)
- VIP tier
- Custom segment

### Templates:
- "We miss you! Here's KSh 50 free to come back 🎰"
- "Hot streak alert! Last 3 rounds were 5x+ 🚀"
- "WEEKEND BONUS: Use code WEEKEND50 for 50% match!"
